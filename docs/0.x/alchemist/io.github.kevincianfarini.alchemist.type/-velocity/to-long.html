fun toLong(lengthUnit: LengthUnit, durationUnit: DurationUnit): Long

Returns the value of this velocity expressed as a Long number of the specified lengthUnit per durationUnit. Infinite values are converted to either Long.MAX_VALUE or Long.MIN_VALUE depending on its sign.
