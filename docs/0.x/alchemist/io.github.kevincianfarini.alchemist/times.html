fun Duration.times(acceleration: Acceleration): Velocity

Returns the resulting Velocity after multiplying the specified acceleration by this duration.

This operation attempts to retain precision, but for sufficiently large values of this duration or the specified acceleration some precision may be lost.

Throws

IllegalArgumentException

if this duration is infinite and acceleration is zero, or if this duration is zero and acceleration is infinite.

operator fun Duration.times(power: Power): Energy

Returns the resulting Energy from applying the specified power over this duration.

This operation attempts to retain precision, but for sufficiently large values of either this duration or power, some precision may be lost.

Throws

IllegalArgumentException

if this duration is infinite and power is zero, or if this duration is zero and power is infinite.
